# 🍊 Radiance C Drops — Vitamin C Serum Landing Page

A minimal, chic, and responsive product landing page for a fictional skincare brand, **Aura Skin Co.** Built using pure HTML, CSS, and vanilla JavaScript.

## 🎨 Design & Theme
- **Aesthetic:** Minimalist, warm, and editorial
- **Color Palette:** Sunset tones (Warm Coral, Soft Peach, Cream background, Deep Espresso text)
- **Target Experience:** Clean storytelling layout focused on product value, key benefits, and conversion.

## ✨ Features
- **Hero Section:** High-impact product headline and primary call-to-action (CTA).
- **Interactive Ingredients:** JavaScript-powered section revealing detailed benefits on hover/click.
- **How to Apply:** Clean 3-step routine breakdown.
- **FAQ Accordion:** Interactive drop-down section for common customer questions.
- **Responsive Layout:** Built with a mobile-first approach using CSS Grid & Flexbox.

## 🛠️ Tech Stack
- **HTML5:** Semantic markup structure
- **CSS3:** Custom properties (variables), Flexbox, Grid, and responsive design
- **JavaScript (ES6+):** DOM manipulation for interactive UI components

## 🚀 Setup & Run
Simply open `index.html` in any browser or launch with Live Server in VS Code.
